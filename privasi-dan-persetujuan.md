# Privasi Data & Draf Surat Persetujuan — SudutKu

> Untuk: pihak sekolah, orang tua/wali, dosen pembimbing, dan peneliti.
> Bagian B dan C adalah **draf**. Sesuaikan dengan format dari kampus/sekolah dan minta persetujuan dosen pembimbing sebelum dipakai.

## A. Ringkasan Perlindungan Data

SudutKu dipakai oleh siswa SMP, yaitu anak di bawah umur. Karena itu aplikasi dirancang agar mengumpulkan data sesedikit mungkin.

| | Keterangan |
|---|---|
| **Yang dicatat** | Kode siswa (mis. `A07H`), nama panggilan, jawaban latihan dan tes, waktu mengerjakan, penggunaan petunjuk, jawaban angket, dan aktivitas di aplikasi (halaman yang dibuka). |
| **Yang TIDAK dicatat** | Nama lengkap, nomor HP, email, alamat, lokasi, foto, suara, kontak, dan ID perangkat asli. Aplikasi tidak meminta izin kamera, lokasi, atau mikrofon. |
| **Tempat penyimpanan** | Hanya di HP yang dipakai (penyimpanan browser). **Tidak ada server** dan tidak ada pengiriman otomatis ke internet. |
| **Keluarnya data** | Hanya saat peneliti menekan *Ekspor data* di Mode Peneliti (dilindungi PIN). |
| **Isi file ekspor** | Kode siswa dan data belajar. **Nama panggilan tidak ikut diekspor.** Setiap HP diberi kode acak (bukan ID asli HP) agar data dari beberapa HP bisa digabung. |
| **Penghubung kode ↔ nama** | Disimpan peneliti di daftar terpisah (kertas/berkas terkunci), **tidak** di dalam aplikasi atau file data. |
| **Pihak ketiga** | Tidak ada iklan, tidak ada analitik (mis. Google Analytics), dan tidak ada SDK pelacak. Layanan hosting (Vercel) hanya menyajikan file aplikasi, bukan data siswa. |
| **Penghapusan** | Data di HP terhapus jika data situs Chrome dihapus. Data hasil ekspor dihapus peneliti setelah penelitian selesai, sesuai ketentuan kampus. |
| **Pelaporan** | Hasil penelitian dilaporkan secara agregat atau dengan kode, tanpa identitas siswa. |

## B. Draf Surat Permohonan Izin kepada Sekolah

> Kepada Yth. Kepala SMPN … Kota Serang
>
> Dengan hormat, saya Rian Subekti, mahasiswa S1 Pendidikan Matematika …, bermaksud melaksanakan uji coba aplikasi pembelajaran **SudutKu** (materi Hubungan Antar Sudut) di kelas … sebagai bagian dari penelitian skripsi berjudul "…".
>
> Uji coba dilaksanakan dalam **2 pertemuan** pada tanggal … dan meliputi tes awal, kegiatan belajar dengan aplikasi, tes akhir, dan pengisian angket. Aplikasi berjalan di HP siswa melalui browser Chrome, dan data hanya tersimpan di HP tersebut sampai dikumpulkan oleh peneliti. Data yang dikumpulkan tidak memuat nama lengkap atau kontak siswa (lihat ringkasan terlampir).
>
> Demikian permohonan ini. Atas perhatian Bapak/Ibu, saya ucapkan terima kasih.

## C. Draf Lembar Persetujuan Orang Tua/Wali

> Saya, orang tua/wali dari siswa bernama ………………… kelas ……,
>
> ☐ **mengizinkan** ☐ **tidak mengizinkan**
>
> anak saya mengikuti uji coba aplikasi pembelajaran matematika SudutKu yang dilakukan oleh Rian Subekti (mahasiswa Pendidikan Matematika …) pada tanggal ………
>
> Saya memahami bahwa:
> 1. Anak saya mengerjakan soal dan mengisi angket di aplikasi selama 2 kali pertemuan di sekolah.
> 2. Aplikasi **tidak** mengambil nama lengkap, nomor HP, foto, atau lokasi. Anak saya hanya memakai kode siswa dan nama panggilan.
> 3. Data dipakai hanya untuk penelitian dan dilaporkan tanpa identitas anak.
> 4. Anak saya boleh berhenti kapan saja tanpa konsekuensi terhadap nilai sekolah.
> 5. Jika memakai HP pribadi, aplikasi dapat dihapus setelah penelitian (Chrome › Setelan › Setelan situs › hapus data situs SudutKu).
>
> ……………, ……………… 2026
> Tanda tangan orang tua/wali: ………………… Nama jelas: …………………

## D. Persetujuan Siswa (dibacakan di kelas)

> "Kalian akan memakai aplikasi SudutKu untuk belajar sudut. Aplikasi ini tidak meminta nama lengkap atau nomor HP kalian, cukup kode di kartu dan nama panggilan. Jawaban kalian dipakai untuk penelitian, bukan untuk nilai rapor. Kalau tidak ingin ikut, kalian boleh bilang ke guru."
